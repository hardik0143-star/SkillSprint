# SkillSprint V2 — Free Short Courses with Credentials

SkillSprint is a lightweight, mobile-first directory of **free, career-relevant courses that can be completed in 15 hours or less** and include a free certificate, badge or platform certification.

## What is new in V2

- 48 curated courses across AI, data, cyber, cloud/IT, coding, business/PM, marketing, professional skills and healthcare/life sciences
- 17 newly added courses in the 6 Oct 2026 V2 refresh
- Personalized “Find my course” quiz
- Seven ready-made 7-day skill roadmaps
- 7-day sprint builder with both a 7-course and 15-hour limit
- India/global, level, provider, category and duration filters
- “New this week” and favorites filters
- Verification freshness badges based on the last manual curation date
- Personal completion tracking
- Personal 1–5 star rating and learner notes saved on-device
- LinkedIn certificate helper: copies the course/certificate details and opens LinkedIn’s Add to Profile flow
- Local curator console with catalog export and learner-data import/export
- PWA manifest + offline caching of the app shell
- Weekly GitHub Action that checks provider catalogs and individual course links
- Human-review queue generated by the weekly checker; it never auto-publishes unverified courses

## Important verification rule

A course belongs in the main catalog only after checking all of these:

1. Learning access is free.
2. The stated certificate / badge / credential is free.
3. Estimated course time is 15 hours or less.
4. The listing links to the official provider.
5. The skill has practical or career value beyond simply collecting certificates.

Provider pages can change. SkillSprint therefore shows a verification date and ships with a weekly source/link checker.

## Free deployment on Vercel

### Easiest GitHub method
1. Extract this ZIP.
2. Upload **the contents of `skillsprint-free-courses`** to the root of a GitHub repository.
3. In Vercel choose **Add New → Project** and import that repository.
4. Framework preset: **Other**.
5. Leave Build Command and Output Directory empty.
6. Deploy.

There is no npm install or framework build step, so the project avoids common `pages/app directory`, Vite and dependency build failures.

## Automatic course radar

The workflow at `.github/workflows/course-watch.yml` runs every Monday and can also be started manually from GitHub Actions. It:

- fingerprints 10 trusted provider/catalog sources;
- checks all listed course URLs for reachability;
- updates `data/source-watch.json`;
- writes any manual-review items to `data/review-queue.md`;
- commits the latest radar results back to the repository.

GitHub Actions needs repository **Contents: read and write** permission if your repository settings override workflow permissions.

## Curator console limitation

V2 is intentionally static and free to host. The curator console is therefore a **browser-local utility**, not a secure multi-user admin backend. A future backend version can add authenticated admin accounts, shared reviews, database-driven moderation and server-side course publishing.
